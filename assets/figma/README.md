# Messenger reference assets

These SVGs are exported component layers from the user-supplied Figma Community
file `9YQqet1VEzpnD2dskZ6roQ`, page `0:11130`.
Reference and screen bindings: `../../docs/design/FIGMA_MESSENGER_IMPLEMENTATION.md`.

Exports were retrieved through the connected Figma design context's asset URLs.
Runtime uses bundled files, without temporary Figma URLs, sample contacts or
sample photos. Natural exported dimensions are declared in `src/dziri/figma.tsx`;
44px hit areas wrap icons without stretching their artwork. Variant exports may
be retained for a subsequent screen. Dziri branding uses the separate approved
ring assets; these UI icons do not replace the logo.

The Settings/People continuation uses exports from Settings `0:13369`, People
`0:13752` and New Message `0:14071`: settings-moon/active/username/phone/people/
messaging, chevron, people-requests/add/wave and group. Settings circle fills are
adapted to Dziri ink; path geometry and white foreground glyphs are retained.
Monochrome People/profile icons receive a white tint in dark appearance. The
reference's Messenger Code, OS chrome and example profile photos are not bundled.
