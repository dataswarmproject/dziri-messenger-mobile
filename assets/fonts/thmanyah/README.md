# Consumer Arabic typeface

Original thmanyah Sans v1.003 OTF files, copied unchanged from the owner's
installed publisher fonts. Family/version and glyph names match Consumer's
bundled v1.003 WOFF2 faces at `apps/dziri/app/fonts/thmanyah` in the Dziri release
source. Inter remains the Latin face, as in Consumer.

Keep the publisher filenames, font bytes and LICENSE.pdf intact. These fonts
are bundled app resources; do not publish a standalone font download or modify,
rename, relicense or claim ownership of the font. Registered face keys only
select the existing regular, medium and bold files; they do not alter them.

OTF supports the current Expo web/Android/iOS font loader. Physical-device
appearance remains a separate verification step.
