# Settings icons

Bundled SVG geometry from Lucide 0.468.0 (`lucide-react/dist/esm/icons`), under
the ISC license in `LICENSE`. Each SVG also retains the complete license notice.
No icon runtime dependency is added.

All glyphs use a 24-unit viewBox, 2-unit strokes, rounded caps/joins, and no fill.
`SettingsIcon` displays them at 20 × 20 within a 40 × 40 neutral circle in both
themes. This follows the requested consistent outline treatment for Settings,
Profile settings, Privacy, and Sign out; other Figma screens retain their artwork.

Sign out uses Lucide's standard `log-out`: an open doorway with an outward arrow.
