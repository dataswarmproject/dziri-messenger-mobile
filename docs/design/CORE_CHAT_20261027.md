# Core chat consistency — 27 October 2026

Standalone now offers reply/reactions/copy/edit/delete in personal and Marketplace
conversations. Touch hold or right-click opens the supplied Android reference's
reaction capsule and bottom action strip. More exposes eligible editing. It uses the same authenticated Dziri
functions as Consumer; no duplicate message database or sender identity is used.

The shared action source is `packages/shared/src/messenger-actions.ts` in the
Dziri monorepo. Sync it with:

```powershell
node scripts/sync-message-actions.mjs --source E:/CodexWorktrees/messenger-tabs/tawasool-mmogram
```

`pnpm check:actions` verifies the checked snapshot and also runs before the
all-platform export. `docs/message-action-contract.json` records source/snapshot
hashes. Changes to the shared rules require a Consumer build and a standalone
sync/build; reactive conversations share data immediately, while UI source does
not distribute itself between binaries.

Edit eligibility is checked again on confirmation; the shared UI window is 15
minutes, matching the canonical personal-message limit. Empty, unchanged and
oversized edits cannot be saved. Destructive actions require the actual sender,
a persisted message, a writable conversation and no immutable agreement event.
Seller-side appearance is not sender ownership. Marketplace store scope stays on
every edit/remove command. Deletion explicitly affects everyone and requires
confirmation; no unsupported "delete for me" option is introduced.

Failures preserve the editor draft and allow retry. Busy state blocks duplicate
commands. Copy uses Expo Clipboard, checks its boolean result, and reports failure
instead of pretending text was copied. It only writes after the user taps Copy;
it never reads the clipboard. Native binaries must be rebuilt for this module.

The outbox also snapshots reply/media data at all external boundaries so retries
keep their original command even if a caller or presentation callback mutates its
copy. A canonical acknowledgement wins over a later failed transport response.

Empty composers expose camera, gallery and microphone shortcuts; typing collapses
them to preserve input width. The thumbs-up action uses the regular send path.
Shared bubble geometry is 18px/4px joined corners with 12px/6px padding; the
approved compact Dziri font, monochrome controls and rose read ticks remain.
The chat header includes Info alongside existing call controls. Reminder, pin,
forward and AI actions remain separate increments.

Checks for this pass: `pnpm test` (45), `pnpm test:ui` (17), typecheck, changed-file
lint, `check:actions`, `check:design`, `check:consistency`, and all-platform export.
Consumer's 60 messaging UI tests and 45 canonical backend contract tests verify
the shared behaviors separately. Physical-device edits/copy and two-client live
convergence remain acceptance gates; no real messages were modified during the
preview review. See the monorepo's
`tasks/messenger-meta-parity/core-chat-verification.json` for final build evidence.
